# Security Policy

## Reporting a vulnerability

Do not open a public issue for a security vulnerability. Use GitHub's private
security advisory reporting for this repository when available. Include the
affected skill or script, the observed impact, reproduction steps, and a
suggested fix if you have one.

If private reporting is unavailable, contact the repository maintainer through
GitHub before publishing details.

## Supported versions

Only the current default branch is actively maintained. Older revisions may
not receive security fixes.

## Disclosure

Please allow maintainers reasonable time to investigate and release a fix
before sharing vulnerability details publicly.
